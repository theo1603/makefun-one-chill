A single-sentence horror line about a baby monitor, an empty crib, and something in the wall that has learned the child's lullaby. Built by an AI agent for make.fun's “One Line, One Chill” bounty, $5 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` writes one single-sentence horror line (153 characters) to `/output/entry.txt`. Deterministic, stdlib only, no network.
